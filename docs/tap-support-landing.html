Características

⚡

Auto-Tapping Configurable

Velocidad adjustable de 1-100 taps por segundo. Control total sobre la tasa de taps.

🔄

Ejecución Multi-Instancia

Ejecuta múltiples instancias en paralelo. Cada una con su propio almacenamiento y configuración.

📊

Métricas en Tiempo Real

Visualiza taps/min, duración y estadísticas de sesión actualizadas en vivo.

👤

Cambio de Usuario

Switch Easily entre diferentes usernames de TikTok sin perder datos.

📜

Historial de Sesiones

Guarda y revisa sesiones anteriores con análisis detallado por instancia.

🎨

UI Moderna TUI

Hermosa interfaz de terminal con Lipgloss y tema oscuro integrado.

Instalación Rápida

# Clonar el repositorio
git clone https://github.com/statick88/tap-support.git
cd tap-support

# Build
make build

# Ejecutar una instancia
./run-multi.sh usuario1

# Ejecutar múltiples instancias
./run-multi.sh -i cuenta1 -r 10 usuario1  # Terminal 1
./run-multi.sh -i cuenta2 -r 15 usuario2  # Terminal 2
./run-multi.sh -i cuenta3 -r 20 usuario3  # Terminal 3

Controles

Space Pausar/Reanudar auto-tapping
T Tap manual (cuando auto-tap está off)
S Iniciar/Detener sesión
R Reiniciar contador
U Cambiar username de TikTok
M Ver métricas de cuenta
H Ver historial de sesiones
Q Salir de la aplicación
